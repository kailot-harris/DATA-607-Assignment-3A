# DATA-607-Assignment-3A
This assignment serves as an extension of Assignment 2A. Here, the pre-existing data pipeline for survey response ingestion into a database is already in place. The important objective for this assignment is determining a global baseline estimate for movies with missing ratings. Some important steps along the way include importing the data from a PostgreSQL database, tidying the data, and calculating necessary parameters. 

Anticipated challenges in this assingment include developing concise R implementations to perform calculations, vector manipulation and finding missing ratings in the database to as placeholders to generate predictions.
