Introduction and Overview

This assignment serves as an extension of Assignment 2A. Here, the pre-existing data pipeline for survey response ingestion into a database is already in place. The important objective for this assignment is determining a global baseline estimate for movies with missing ratings. Some important steps along the way include importing the data from a PostgreSQL database, tidying data, and calculating necessary parameters.

Anticipated challenges in this assignment include developing concise R implementations to perform calculations, vector manipulation and finding missing ratings in the database to as placeholders to generate predictions.

An empty data frame is constructed with all possible combinations of respondent_id and movie_id, while ratings is left empty. The ratings column is populated by a similar join pattern to above: the ratings frame is joined into the empty frame by unique combinations of repondent_id and movie_id. From there, the movie titles are input by joining the movies frame to the new frame by the movie_id key. A head on the partially-filled data frame demonstrates missing values for movie_id = 1.

Global Mean Determination

A first step in generating predicted rating values for missing ratings was establishing the global mean for the dataset mu. mu was calculated via a series of piped summarize commands, with missing values removed before computing mean values. The global mean rating was determined to be approximately 3.76.

mu <- df |>
  group_by(movie_id) |>
  summarize (mean_rating_movie = mean(rating, na.rm=TRUE)) |>
  summarize (global_mean = mean(mean_rating_movie))

mu[1,1]
# A tibble: 1 × 1

        <dbl>
1        3.76

From there, user biases were investigated. Here, a series of piped summarize, mutate, and select commands creates the final data frame containing just the respondent_id and the “user bias value” or b_user.

b_user <- df |>
  group_by(respondent_id) |>
  summarize (mean_rating_respondent = mean(rating, na.RM=TRUE)) |>
  mutate(b_user = mean_rating_respondent - as.numeric(mu[1,1])) |>
  select(respondent_id, b_user)

A similar calculation is performed to find the movie bias, or in other words, the extent to which certain movies are preferred in this data set. The average rating for each movie is calculated, and then the global mean is subtracted from that quantity to yield a bias value for each movie, b_movie.

b_movie <- df |>
  group_by(movie_id) |>
  summarize(b_movie = mean(rating, na.RM = TRUE)-as.numeric(mu[1,1]))

Global Baseline Estimates

Global baseline estimates will be generated for all mock respondents for any movie they left unrated. The global baseline is recast as a single numeric value mu before computing estimates. Then, the df_estimates data frame is generated by joining in the columns b_user and b_movie to df_missing, the frame hosting only missing data. Then, a column for the global_mean is added via the mutate function, and the rating estimates, rating_est, are calculated for each row by adding the global_mean, b_user, and b_movie columns. The new frame is then pruned to hold only respondent_id, movie_id, title, and rating_est and cast as df_final. The firsat few rows of df_final are displayed to confirm estimates were generated.

mu <- as.numeric(mu[1,1])
  
df_estimates <- df_missing |>
  left_join(b_user, by = "respondent_id") |>
  left_join(b_movie, by = "movie_id") |>
  mutate(global_mean = mu,
         rating_est = global_mean+b_user+b_movie)

df_final <- df_estimates |> select(respondent_id, movie_id, title, rating_est)

Findings and Recommendations

In this Assignment, a new analysis pipeline was developed to input data hosted in a local PostgreSQL database into R, tidy the data before analysis, and compute important parameters for the estimation process. Ratings values were estimated for each unique respondent and movie combination with a missing rating value. This emulates the real-world application of recommender systems to suggest new movies to a viewer. For instance, the system may recommend “One Battle After Another (2025)” to respondents with respondent_id values of 4 and 6, since their estimated rating is roughly 4.5.

Improvements to this work could include revisiting the synthetic data generation phase in Assignment 2A to generate quasi-random ratings values, rather than user-input hardcoded values. Additionally, since a mean value is used to generate estimated ratings, confidence intervals could be determined for each of the estimates provided.
